# Bilibili management function usage guide
## 📋 Function Overview
The new Bilibili management function is specially designed for novice users, providing the simplest and most intuitive account management and submission experience.
## 🎯 Core functions
### 1. Account management- **Add account**: Supports cookie import method, safe and reliable- **Multiple account support**: You can add multiple Bilibili accounts- **Account Status**: Real-time display of account health status- **Quick Delete**: Delete unwanted accounts with one click
### 2. Submission and upload- **Slice submission**: Submit directly on the slice details page- **Batch Submission**: Supports uploading multiple slices at the same time- **Account Selection**: Flexible choice of submission account- **Partition settings**: Support all partitions of station B
## 🚀 Usage process
### Step 1: Add Bilibili account
1. **Enter the settings page**   - Click "Settings" on the left navigation bar   - Select the "Bilibili Account Management" tab
2. **Add account**   - Click the "Manage Bilibili Account" button   - Select the "Account Management" tab   - Click the "Add Account" button
3. **Get Cookie**   - Open Bilibili website and log in   - Press F12 to open developer tools   - Click on the Network tab   - refresh page   - Find any request and click to view it   - Find the Cookie field in Request Headers   - Copy the cookie value (without the "Cookie: " prefix)
4. **Import account**   - Enter the account nickname (for identification)   - Paste cookie content   - Click "Add Account"
### Step Two: Submit Slices
1. **Select slice**   - Enter the project details page   - Find the slice you want to contribute to   - Click the "Contribute" button on the slice card
2. **Configure submission information**   - Select the Bilibili account you want to use   - Select video partition   - Enter video title   - Add description and tags (optional)
3. **Start Submission**   - Click the "Start Submission" button   - The system will process submissions in the background   - After the submission is completed, a success prompt will be displayed.
## 💡 Tips for use
### Cookie Obtaining Tips- **Recommended browsers**: Chrome, Edge, Firefox- **Get location**: Developer Tools → Network → Any Request → Request Headers- **Format requirements**: Complete cookie string, separated by semicolon- **Validity period**: Cookies usually have a validity period of 7-30 days and need to be obtained again after expiration.
### Account management skills- **Nickname settings**: Use meaningful nicknames, such as "main account" and "backup account"- **Regular Check**: It is recommended to check the account status regularly and update expired cookies in a timely manner.- **Multiple account strategy**: You can set up accounts for different purposes, such as "test account" and "official account"
### Submission optimization tips- **Title Optimization**: Use attractive titles and avoid being too long- **Partition Selection**: Choose the appropriate partition to improve the recommendation effect- **Tag Settings**: Add relevant tags to increase exposure- **Batch submission**: For multiple related slices, you can submit in batches
## ⚠️ Notes
### Safety reminder- **Cookie Security**: Cookie contains login information, please keep it safe- **Account Security**: Do not log in on public devices- **Regular updates**: It is recommended to update cookies regularly to avoid expiration
### Usage restrictions- **Upload restrictions**: Comply with the upload rules and restrictions of Bilibili- **Content Standards**: Ensure that the content complies with Bilibili community standards- **Frequency Control**: Avoid frequent submissions to prevent triggering risk control
### troubleshooting- **Invalid Cookie**: Check cookie format and validity period- **Upload failed**: Check network connection and account status- **Partition Error**: Confirm whether the partition ID is correct
## 🔧 Technical description
### Supported login methods- **Cookie Import** (recommended): the safest and will not trigger risk control- **Account and password login**: Traditional method, there may be a verification code- **Scan QR code to log in**: requires Bilibili APP, may trigger risk control
### Upload mechanism- **Direct API call**: Use the official API of Bilibili, stable and reliable- **Multiple Upload**: Supports multi-part upload of large files- **Retry Mechanism**: Automatically retry failed uploads- **Progress Tracking**: Display upload progress in real time
## 📞Technical support
If you encounter problems, you can:1. Check the system log for detailed error information2. Check network connection and account status3. Re-obtain cookies and update account4. Contact technical support for assistance
